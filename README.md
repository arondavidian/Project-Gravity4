# Project-Gravity4
Projet basé sur le jeu de puissance 4, développée pour jouer à 2 ou avec une intelligence artificielle.
3 niveaux sont disponibles, chaque niveau à un niveau de l'IA supérieur au précédent.
J'ai utilisé la technique minimax qui analyse chaque coup possible, en dépendant du niveau de l'IA, le nombre de coup regarder à l'avance est supérieur à chaque fois.
Ce projet m'a pris 5 mois pour le faire, je me suis aidé de l'IA et des vidéos youtube pour apprendre comment écrire le code et à comprendre comment faire marcher le système.
Ce projet à été réalisé par Aron DAVIDIAN.
Possibilité de rajouter des dimension en lien avec le nom du jeu pour s'éloigner un peu du jeu original.
